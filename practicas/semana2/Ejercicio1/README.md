# Ejercicio 1 - Semana 2: Cálculo de Edad

Programa que solicita por teclado el año actual y el año de nacimiento de una persona para calcular su edad.

## 🛠️ Conceptos y Observaciones

* **`System.out.print`:** Cambiado para pedir los datos en la misma línea de la pregunta sin hacer salto de línea.
* **`System.out.printf`:** Utilizado para mostrar los resultados formateados sin tener que concatenar con `+`.
